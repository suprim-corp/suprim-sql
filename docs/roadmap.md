# Roadmap — suprim-sql

## v0.1 — Core SQL Client
- [ ] Kết nối PostgreSQL, MySQL, SQLite
- [ ] SQL editor với syntax highlighting
- [ ] Chạy query, hiển thị kết quả dạng bảng
- [ ] Schema browser (sidebar: databases → tables → columns)
- [ ] Lưu và khôi phục connections

## v0.2 — Table Editor
- [ ] Browse table data (phân trang)
- [ ] Sửa dữ liệu inline — preview SQL trước khi commit
- [ ] Thêm / xóa row
- [ ] Filter và sort trực tiếp trên bảng

## v0.3 — Multi-tab & History
- [ ] Nhiều tab query song song
- [ ] Query history — xem lại và chạy lại query cũ
- [ ] Autocomplete (keywords + tên bảng/cột)
- [ ] SQL formatter

## v0.4 — NoSQL Support
- [ ] Redis — browse keys, xem value theo type (string/hash/list/set/zset)
- [ ] Redis Pub/Sub
- [ ] MongoDB — browse collections, filter documents

## v0.5 — Security & Connectivity
- [ ] SSH tunnel
- [ ] TLS / SSL
- [ ] Lưu credentials an toàn (OS keychain)
- [ ] MSSQL support

## v0.6 — Export & Import
- [ ] Export kết quả query ra CSV, JSON, Excel
- [ ] Import CSV vào table

## v0.7 — AI Assistant
- [ ] Chat panel hỏi AI về SQL
- [ ] AI tự động viết query từ mô tả tự nhiên
- [ ] Giải thích query

## v0.8 — Schema & Diagram
- [ ] ERD diagram — visualize schema dạng đồ thị
- [ ] Xem indexes, foreign keys, constraints

## v0.9 — Polish
- [ ] Dark / light theme
- [ ] Workspaces — lưu layout và tab state
- [ ] Auto-update

## v1.0 — Release
- [ ] macOS `.dmg`, Linux `AppImage` + `.deb`, Windows `.msi`
- [ ] Freemium model: 3 connections miễn phí, Pro không giới hạn
